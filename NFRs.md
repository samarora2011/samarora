# Non-Functional Requirements (NFRs)

## NFR1 - Usability

**Category:** Usability  
**Subcategory:** Intuitive Interface  
**Description:** Interface is clean, responsive, and navigable for both customers and admins.

## NFR2 - Performance

**Category:** Performance  
**Subcategory:** Response Time  
**Description:** Most pages load within 5 seconds (4/5 passed)

## NFR3 - Reliability

**Category:** Reliability  
**Subcategory:** System Availability  
**Description:** System availability confirmed (HTTP 200, <5s response)

## NFR4 - Security

**Category:** Security  
**Subcategory:** Secure Authentication  
**Description:** HTTPS authentication and secure password handling

## NFR5 - Compatibility

**Category:** Compatibility  
**Subcategory:** Cross Browser Support  
**Description:** Chrome and Firefox compatibility verified
